# Form Data Mahasiswa — PHP Saja

Aplikasi latihan yang seluruh source code-nya berada dalam satu file `index.php`. Tidak memakai file CSS atau JavaScript terpisah.

## Fitur
- Form input nama, NIM, jurusan, dan semester.
- Menyimpan data dalam array PHP pada session.
- Menampilkan data mahasiswa dalam tabel.
- Validasi input dan perlindungan output HTML.

## Menjalankan di Windows dengan XAMPP
1. Letakkan folder `form-mahasiswa` di `C:\\xampp\\htdocs\\`.
2. Jalankan Apache dari XAMPP.
3. Buka http://localhost/form-mahasiswa/ di browser.

## Catatan
PHP menghasilkan HTML yang diperlukan browser untuk menampilkan form dan tabel. Source code ditulis dalam satu file PHP tanpa CSS dan JavaScript terpisah. Data tersimpan sementara di session, bukan database.
