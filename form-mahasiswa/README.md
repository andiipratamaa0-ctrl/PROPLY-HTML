# Form Data Mahasiswa (PHP)

Aplikasi sederhana untuk latihan form HTML, array PHP, validasi input, dan tabel HTML.

## Fitur
- Input nama, NIM, jurusan, dan semester.
- Menampung data dalam array PHP.
- Menampilkan hasil input dalam tabel.
- Validasi input sisi server dan escaping output HTML.
- Tampilan responsif untuk layar kecil.

## Teknologi
- PHP 8+
- HTML5
- CSS3

## Cara menjalankan di Windows dengan XAMPP
1. Salin folder `form-mahasiswa` ke `C:\\xampp\\htdocs\\`.
2. Jalankan Apache dari XAMPP.
3. Buka http://localhost/form-mahasiswa/ di browser.

## Catatan
Versi ini tidak memakai database. Array hanya berisi data selama satu permintaan, sehingga data tidak disimpan permanen dan akan hilang setelah halaman dimuat ulang.
